# Thumbpad v0.1.15

- Support Ctrl, Alt, and Shift with mapped left, right, and middle mouse buttons while touchpad controls are active.
- Prevent modified click keys from triggering application keyboard shortcuts instead of starting a drag.
- Keep Windows-key shortcuts and keyboard keys pressed before touchpad activation unchanged.

Lift your finger before starting a keyboard shortcut that uses a mapped click or scroll key.

Use `thumbpad-setup-x64.exe` for Windows 11 x64 installation. A compatible built-in Precision Touchpad is required.
