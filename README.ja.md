# Thumbpad

タッチパッドに触れながら、キーボードのキーでクリック・ドラッグ・スクロールできるWindows常駐アプリです。ポインターを指で弾いて動かすトラックボールモードも使えます。

ThumbSenseに着想を得た独立したアプリです。Windows 11の内蔵Precision Touchpadを対象とした実験段階のソフトウェアで、機種ごとの互換性を検証しています。

## インストール

1. [最新リリース](https://github.com/kathoc/thumbpad/releases/latest)から **thumbpad-setup-x64.exe** をダウンロードします。
2. インストーラーを実行し、Thumbpadを起動します。
3. タッチパッドに指を置いてから、クリックやスクロールのキーを押します。

Windows 11 x64向けに、現在のWindowsアカウントへインストールします。トレイの **Start with Windows** で自動起動を設定できます。現在の配布ファイルはコード署名されていません。

アンインストールはWindowsの「設定 → アプリ → インストールされているアプリ」から行えます。設定ファイルは残ります。

## キー操作

**初期設定はCVBモードです。** トレイアイコンを右クリックし、**CVB mode** または **SDF mode** を選んで切り替えます。選択は保存され、すぐに反映されます。

| 操作 | CVBモード | SDFモード |
| --- | --- | --- |
| 左クリック | V または N | F または J |
| 右クリック | C または M | D または K |
| センタークリック | G または H | C または M |
| 上下スクロール | Bを押しながら指を上下に動かす | SまたはLを押しながら指を上下に動かす |
| 左右スクロール | Shift+Bを押しながら指を左右に動かす | Shift+SまたはShift+Lを押しながら指を左右に動かす |
| ドラッグ | クリックキーを押しながら指を動かす | クリックキーを押しながら指を動かす |
| 一時停止・再開 | Ctrl+Alt+F12 | Ctrl+Alt+F12 |

キーを押す前にタッチパッドへ指を置いてください。長いドラッグでは、クリックキーを押したまま指を離して置き直せます。左右の手で左クリックキーを押し替えるときは、両方のキーを重ねて押してから片方を離せます。

タッチパッドに触れる前から押していたキーは、離すまで通常のキーボード入力として扱います。タッチパッド操作が有効な間は、Ctrl・Alt・Shiftとクリック用キーを組み合わせて、修飾キー付きのクリックやドラッグができます。クリック用キーを文字として使うショートカットは、指を離してから入力してください。Windowsキーを使うショートカットはそのまま通ります。CVBモードではS/D/Fを通常入力に使えるため、ゲームの操作キーと組み合わせやすくなります。Raw Inputを必要とするゲームや入力注入を制限するゲームは個別の確認が必要です。

スクロール方向は初期設定で反転しています。トレイの **Invert vertical scroll** と **Invert horizontal scroll** で変更できます。スクロール中にShiftを押すと、上下と左右を切り替えられます。Excelには横スクロールの互換処理があり、バージョンや画面によって動作が異なる場合があります。

## ポインターと慣性

初期設定のマウスモードではWindowsの通常のポインター移動を使います。トレイの **Trackball pointer mode (off = mouse)** をオンにすると、指を弾いて離した後もポインターが減速しながら動きます。

- パッドに再び指を置くと慣性が止まります。
- 小さな動きの慣性を抑え、静止中の揺れや離す瞬間の単発の動きを除外します。
- **Trackball pointer faster / slower** でポインター感度を調整できます。
- **Hold pointer after inertia stop** で、慣性を止めた接触後の短い固定を切り替えます。初期値は100msです。
- **Inertial scrolling** で、キーを使う上下・左右スクロールの慣性を切り替えます。

有効な指が2本以上になると、Windowsの通常のタッチパッドジェスチャーを使えるよう、トラックボールのポインター移動を止めます。有効な指をすべて離し、1本指で新たに触れるとポインター操作を再開できます。

### マウス入力の互換性

キー操作によるポインター移動とトラックボールの慣性は、Windows標準の相対マウス入力で送ります。デスクトップアプリ、CAD、ゲームの視点操作にも共通の入力形式を使います。

小数の移動量を更新間で保持し、低速や斜め方向の慣性にも反映します。相対移動はデスクトップの範囲に制限されないため、画面端を超えて視点を回転できます。操作対象のウィンドウを切り替えると、動いている慣性は止まります。

デスクトップの移動にはWindowsのマウス感度や加速設定が反映されます。相対移動を直接受け取るアプリでは、そのアプリ側の感度が使われます。Thumbpad側の感度は **Trackball pointer faster / slower** で調整できます。

## 端からの誤操作防止

初期設定では、左右各12%と上15%を操作開始の禁止エリアにしています。

- 有効エリアから接触を始めた指は、そのまま端まで動かせます。
- 禁止エリアから接触を始めた指は、離すまで操作に使いません。
- 禁止エリアに指を置いたまま、別の指を有効エリアから置いて動かせます。
- 接触の瞬断や置き直しには500msの猶予があります。
- クリックやスクロールのキーを保持している間は、端から置き直して操作を再開できます。

トラックボールモードでは、接触位置が上端や左右端へ近づくほど慣性を強く減速します。有効エリアとの境界では通常の慣性になり、禁止エリアの奥へ入るほど、指を離した後の距離と時間が短くなります。最も外側の端では慣性が止まります。手のひらと判定された接触も位置の判定に使います。

## 設定

トレイの **Edit settings** から内蔵のJSON設定画面を開きます。**Save and close** で検証・保存して即時反映し、**Cancel** で編集を破棄します。

| 設定項目 | 内容 |
| --- | --- |
| `key_mode` | `"cvb"` または `"sdf"`。初期値は `"cvb"`。 |
| `pointer_mode` | `"mouse"` または `"trackball"`。初期値は `"mouse"`。 |
| `trackball_pointer_speed` | ポインター感度。0.25–4.0、初期値1.25。 |
| `pointer_inertia_min_travel_px` | ポインター慣性が始まるまでの確認済み相対移動量。0–1000単位、初期値12。 |
| `pointer_inertia_strength` | ポインターの慣性の強さ。0–2、初期値1。0で慣性を無効にします。 |
| `pointer_inertia_decay` | ポインターの減速。1–20、大きいほど早く止まります。初期値5。 |
| `pointer_stop_hold_enabled` / `pointer_stop_hold_ms` | 慣性停止後の固定の有効・無効と時間。0–2000ms。 |
| `inertia_enabled` / `inertia_decay` | スクロール慣性の有効・無効と減速。減速は1–20。 |
| `edge_side_percent` / `edge_top_percent` | 左右と上の禁止エリア幅。0–45%と0–80%。 |
| `edge_grace_ms` | 接触の再開猶予。0–5000ms、初期値500。 |
| `edge_pointer_guard` | 禁止エリアの接触によるポインター移動抑制。 |
| `drag_pixels_per_pad_width` / `drag_pixels_per_pad_height` | パッド全幅・全高に対するキー保持ドラッグの移動量。 |
| `scroll_units_per_pad_width` / `scroll_units_per_pad_height` | 左右と上下のスクロール量。120単位で1ノッチです。 |
| `scroll_invert` / `scroll_horizontal_invert` | 上下と左右のスクロール方向。 |

設定ファイルは `%LOCALAPPDATA%\Thumbpad\settings.json` に保存されます。

## 更新とトレイ操作

**Check for updates** で手動確認できます。**Automatic updates** をオンにすると、起動後と1日ごとに新しいリリースを確認します。ダウンロード・インストールの前には確認画面が出ます。

トレイアイコンのダブルクリックで診断画面を開けます。診断画面を閉じても常駐します。完全に終了する場合は、トレイの **Exit** を選びます。

## 対応環境と困ったとき

- 接触情報を公開する内蔵Windows Precision Touchpadが必要です。古い独自方式やPS/2のみのタッチパッドは未対応です。
- 指を動かしたときに、診断画面の **HID reports** が増えるか確認してください。増えない機種・セッションは現在対応していません。
- 端の移動抑制やキー操作中に外付けマウスを同時に動かすと、その移動も抑制される場合があります。
- 管理者権限のアプリ、セキュアデスクトップ、一部ゲームでは生成したマウス入力が制限されます。
- タップでクリックを併用すると、キー操作に加えてクリックが発生する場合があります。
- 入力が押しっぱなしに感じられたら、Ctrl+Alt+F12で一時停止するか、終了して再起動してください。

操作から画面への反映までの遅延や、複数メーカーの実機互換性は包括的な測定を終えていません。

## プライバシーとサポート

更新確認とリリース取得にGitHubを使います。入力した文字の記録・送信や利用統計の送信はありません。診断はカウンターとデバイス情報を表示します。更新エラーとクラッシュ情報は `%LOCALAPPDATA%\Thumbpad` にローカル保存します。

不具合は、PCの機種名・Windowsのバージョン・Thumbpadのバージョン・再現手順とともに [GitHub Issues](https://github.com/kathoc/thumbpad/issues) へお寄せください。

## 開発

Rust 1.96.0、Visual Studio C++ Build Tools、Windows SDK、Inno Setup 6.3以降が必要です。`cargo test --locked` と `./installer/build.ps1` で検証・ビルドでき、配布物は `dist` に作成されます。ライセンスはMITです。
